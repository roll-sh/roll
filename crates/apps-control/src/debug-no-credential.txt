# Fields with a credential's name on a type that derives `Debug`, holding no credential
# (roll-debug-scan's `beyond_roll_secrets`): `Type.field: why`. A type that holds one keeps it in
# a type that redacts itself or prints itself by hand (or derives no `Debug`); a line goes here
# only once someone has checked the field holds none.
Conditions.cookies: the cookie names a site rule matches on, never a value
Domain.token: the `_roll-challenge` TXT value a custom domain proves itself with, public in its DNS
EnvRow.secrets_seen: roll secrets' folder digest last acted on (keys, versions, fingerprints), no value
GitLogin.secret: the name of the project secret the password is read from, never its value
Heartbeat.token_hash: the SHA-256 of a random token roll made and showed once, never the token
HookUrl.token_hash: the SHA-256 of a random token roll previews made (`?roll_hook=`), never the token
PrivateNetwork.secret: the `roll://` reference the config is read from, never what it reads
Visitor.cookies: the names of the cookies a request sent, never their values
