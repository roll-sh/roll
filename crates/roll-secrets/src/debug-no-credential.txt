# (crypto.rs, `every_debug_type_with_a_credential_is_checked`): `Type.field: why`. A type that
# holds one keeps it in a `Value` (it redacts itself), prints it by hand, or gets a line in
# `no_debug_prints_a_credential` instead.

Rotation.credential: a managed link's credential id (its state's `credential`), never its value
SyncPreview.credentials: the keys a sync reads its platform credentials from, names only
SyncPreview.missing_credentials: credential keys the folder doesn't set, names only
