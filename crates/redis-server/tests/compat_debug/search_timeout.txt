# Query timeouts like Redis 8's bundled RediSearch 8.10.1, made deterministic by the module's
# debug wrappers: _FT.DEBUG FT.SEARCH|FT.AGGREGATE|FT.PROFILE|FT.HYBRID … TIMEOUT_AFTER_N n
# DEBUG_PARAMS_COUNT k times the query out once its index reader gave n results. The wrappers'
# argument errors, ON_TIMEOUT RETURN (partial results, the RESP3 warning, the profile's
# warning), FAIL (the error, FT.PROFILE's empty results) and RETURN-STRICT, cursors timing out
# chunk by chunk, the internal _FT.* commands and _FT.CURSOR PROFILE. Indexes are created on
# an empty keyspace and dropped at the end; configs are put back.
