# The latency monitor: spikes of slow commands (DEBUG SLEEP) once latency-monitor-threshold is
# set, and LATENCY LATEST/HISTORY/GRAPH/DOCTOR/RESET over them (times and latencies vary, so
# those replies compare by shape).

FLUSHALL
LATENCY RESET
CONFIG GET latency-monitor-threshold
LATENCY DOCTOR
LATENCY GRAPH command
LATENCY LATEST
CONFIG SET latency-monitor-threshold 5
