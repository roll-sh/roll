# Query timeouts and cursors like Redis 8's bundled RediSearch 8.10.1, the deterministic part
# (tests/compat_debug/search_timeout.txt times queries out with _FT.DEBUG): TIMEOUT and
# ON_TIMEOUT's arguments, the foreground cap of a query's timeout (WORKERS 0) and its RESP3
# warning, FT.HYBRID WITHCURSOR's cursor pair, and cursors keeping their first chunk's term
# expansions, readers and IDFs. Indexes are created on an empty keyspace and dropped at the
# end; configs are put back.

# TIMEOUT's argument.
FT.SEARCH idx * TIMEOUT
