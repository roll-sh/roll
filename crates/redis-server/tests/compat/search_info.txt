# Where the query counters count (`TotalGlobalStats_CountQuery` once a chunk is replied,
# `QueryErrorsGlobalStats_UpdateError` where an error is, `QueryWarningsGlobalStats_UpdateWarning`
# for a chunk's warnings, RESP2's too): an FT.AGGREGATE cursor's first chunk is a query, its
# reads and FT.SEARCH WITHCURSOR's chunks commands only; FT.HYBRID WITHCURSOR's reply none, its
# subqueries' reads commands; a pipeline's error after the first results (RESP3's warning)
# leaves the query uncounted; the warnings are the coordinator's (FT.HYBRID WITHCURSOR's the
# shard's); errors count the same in MULTI and scripts.
