# Search execution regressions from differential fuzzing.

# RETURN naming the SORTBY field alongside others (the overridden lookup key kept its place).
FLUSHALL
FT.CREATE i ON HASH PREFIX 1 d: SCHEMA t1 TEXT SORTABLE n NUMERIC
HSET d:1 t1 "b word" n 5
HSET d:2 t1 "a word" n 7
FT.SEARCH i word SORTBY t1 ASC RETURN 2 n t1
FT.SEARCH i word SORTBY t1 DESC RETURN 3 n t1 n
FT.SEARCH i word SORTBY n ASC RETURN 2 t1 n
FT.AGGREGATE i word LOAD 2 @n @t1 SORTBY 2 @t1 ASC
FT.DROPINDEX i
