# FT.SEARCH WITHCURSOR and FT.CURSOR READ of a search cursor: the search pipeline (scorer,
# sorter, pager, loader, highlighter) read chunk by chunk, the first chunk's total (later ones
# count nothing, the sorter drained the query), FT.SEARCH's row shapes (ids, scores, payloads,
# sort keys, RETURN, NOCONTENT, HIGHLIGHT/SUMMARIZE), RESP3, JSON, the optimizer's streaming
# pager (DIALECT 4) and the cursor limits. Every cursor is drained or deleted.

# KNN under a cursor: the results by distance.
FT.CREATE hv ON HASH PREFIX 1 h: SCHEMA t TEXT v VECTOR FLAT 6 TYPE FLOAT32 DIM 2 DISTANCE_METRIC L2
HSET h:1 t hello v "\x00\x00\x80\x3f\x00\x00\x80\x3f"
HSET h:2 t world v "\x00\x00\x00\x40\x00\x00\x00\x40"
HSET h:3 t hello v "\x00\x00\x40\x40\x00\x00\x40\x40"
!capture c FT.SEARCH hv "*=>[KNN 3 @v $b]" WITHCURSOR COUNT 1 PARAMS 2 b "\x00\x00\x00\x00\x00\x00\x00\x00" DIALECT 2
FT.CURSOR READ hv {$c}
FT.CURSOR READ hv {$c} COUNT 5
!delta search_coord_*,search_shard_*,search_total_queries_processed,search_total_query_commands INFO search_queries search_warnings_and_errors search_coordinator_warnings_and_errors
